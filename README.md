# Travel-Bucket-List (Collect Travel Destinations)
Locations you want to visit + Reviews from others
- Screen 1: Login
- Screen 2: Register
- Screen 3: My Locations (Bucket List)
- Screen 4: Add location (Name, Country, Picture)
- Screen 5: Location details (Reviews, Tips from others)
- Screen 6: Settings

## Password Reset

Password reset emails are sent via Firebase Auth's default sender
(`noreply@<project-id>.firebaseapp.com`). Some email providers like
Outlook particular block or filter these emails before
they reach the inbox or spam folder.

**For testing, use a Gmail account.** Gmail reliably receives these emails instead of Outlook.
